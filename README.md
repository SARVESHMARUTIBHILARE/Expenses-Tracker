# 💰 Expenses Tracker

A modern and user-friendly **Expenses Tracker Web Application** designed to manage income, expenses, budgets, transactions, and financial analytics. The system provides monthly and yearly expense analysis with graphical representations and stores transaction data using a MySQL database.

---

## 📌 Project Overview

The Expenses Tracker helps users record and manage their daily financial activities. Users can add income and expenses, view their current balance, analyze spending patterns, and monitor their financial performance through interactive dashboards and graphs.

The application is designed to work with **Microsoft Edge**, **Python Flask**, and **MySQL/XAMPP**.

## ✨ Features

### 📊 Dashboard
- Total Income
- Total Expenses
- Current Balance
- Recent Transactions
- Expense Summary
- Financial Insights
- Graphical Data Representation

### 💸 Expense Management
- Add new expenses
- Select expense category
- Enter amount
- Add transaction description
- Select transaction date
- View all expenses
- Delete transactions

### 💰 Income Management
- Add income transactions
- Track total income
- View income history
- Calculate available balance

### 📅 Monthly Analysis
- Monthly income
- Monthly expenses
- Monthly balance
- Monthly expense trends
- Category-wise monthly expenses
- Monthly graphical analysis

### 📆 Yearly Analysis
- Yearly income
- Yearly expenses
- Yearly balance
- Yearly spending trends
- Year-wise graphical representation

### 📈 Graphs & Analytics
The application provides different graphs to understand financial activities easily.

Examples:
- Income vs Expense
- Monthly Expense Trend
- Yearly Expense Trend
- Category-wise Expenses
- Balance Analysis

### 🔍 Transaction Management
- Search transactions
- Filter transactions
- View transaction details
- Delete transactions
- Sort financial records

### 🗂️ Expense Categories

The application can manage categories such as:

- 🍔 Food
- 🚗 Transport
- 🛍️ Shopping
- 🏠 Bills
- 🎓 Education
- 💊 Health
- 🎬 Entertainment
- ✈️ Travel
- 💻 Technology
- 📦 Other

### 💾 Database
Transaction information can be stored in a **MySQL database** using XAMPP.

The database stores:
- Transaction ID
- Transaction type
- Amount
- Category
- Description
- Transaction date
- Created date
